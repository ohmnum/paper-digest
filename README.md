# 논문 데일리

LLM 학습 데이터(선택·변환·표상)와 행동 교정 관련 새 논문을 매일 모아서, 한국어 불릿으로 요약해 보여주는 사이트입니다.

- 사이트: https://www.hyeongminkim.com/paper-digest/
- 출처: arXiv(키워드 검색)와 Hugging Face Daily Papers
- 처리: Claude가 관련도를 0~10점으로 매기고, 7점 이상만 남깁니다. 남은 논문은 문제/방법/결과/한계 불릿으로 요약하고, 제안 방법 그림을 고릅니다. 그림은 arXiv HTML 판이 있는 논문만 나옵니다.
- 관심 주제와 키워드: `config.json`을 고치면 다음 수집부터 반영됩니다.

## 돌리기
```
python collect.py            # 최근 2일 (이미 본 논문은 건너뜀) → docs/data 저장 → git push
python collect.py --days 7   # 여러 날 한꺼번에
```
매일 아침 PC의 Windows 작업 스케줄러(작업 이름 PaperDigest)가 실행합니다.

## 저장·질문·노트 (Cloudflare)
메모·★·읽음 서버 저장, 논문에 질문(Gemini), 논문과 별개인 노트는 Cloudflare Workers 서버가 맡습니다 (설정은 `CLOUDFLARE.md`, 비밀값 3개). 사이트 맨 아래 **관리 키** 칸에 키를 넣으면 켜집니다. GitHub Pages 주소에서도 `docs/data/server.json` 에 Cloudflare 주소가 적혀 있으면 같이 됩니다 (예전의 GitHub 토큰 동기화는 없어졌음).
관리 키를 넣은 브라우저만 서버 저장·질문·노트가 되고, 방문자는 읽기만 합니다 (방문자의 ★·메모는 그 브라우저에만 저장).

## 사이트 사용법
- 카드를 누르면 요약 불릿, 왜 볼 만한지, 그림, 링크가 펼쳐집니다. 펼치면 읽음으로 표시됩니다.
- ★ 보관, ✓ 읽음, 검색, 태그 필터를 쓸 수 있습니다.
- 📝 를 누르면 오른쪽에 메모 창이 열리고, 그 아래에서 논문에 질문할 수 있습니다 (관리 키 필요). 답은 "메모에 붙이기"로 메모에 옮길 수 있습니다.
- 📒 노트: 여러 논문을 묶어 정리한 내용, 실험 정리 등 (관리 키 필요).
